# 🚀 Getting Started

## Clone Repository

```bash
git clone https://github.com/ABHINAVSINGHSHEKHAWAT/FlashAi.git

cd FlashAi
```

---

## Install Dependencies

### Frontend

```bash
cd client

npm install
```

### Backend

```bash
cd server

npm install
```

---

## Environment Variables

Create a `.env` file inside the server folder.

```env
PORT=

DATABASE_URL=

OPENAI_API_KEY=

JWT_SECRET=
```

---

## Run the Application

### Backend

```bash
npm run server
```

### Frontend

```bash
npm start
```

# 🎯 Why Flash.ai?

Flash.ai is designed as an all-in-one AI productivity platform that combines multiple AI-powered tools into a single seamless experience. Instead of switching between different applications, users can create articles, generate blog ideas, produce AI images, edit images, and review resumes—all from one intuitive dashboard.

This project demonstrates:

- Full-Stack Web Development
- RESTful API Design
- AI API Integration
- Authentication & Authorization
- PostgreSQL Database Management
- Responsive UI Development
- SaaS Application Architecture
